#  Banking System Simulation 

##  Problem Statement

Banks require secure and efficient systems to manage customer transactions.
This project is a **Java-based Banking System Simulation** that replicates core banking operations with a user-friendly interface and database integration.

---

##  Objectives

* Simulate real-world banking operations
* Manage user accounts and transactions securely
* Apply object-oriented programming concepts

---

##  Key Features

*  Create accounts (Savings / Current)
*  User authentication (Username & Password)
*  Deposit and withdraw money
*  Transfer funds between accounts
*  Balance inquiry
*  Transaction history tracking
*  Interactive UI using JavaFX

---

##  Technologies Used

* **Java (Core Java, OOP concepts)**
* **JavaFX** (for GUI)
* **JDBC + MySQL** (for database connectivity)
* Developed using Eclipse IDE
